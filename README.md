# Автотесты для сервиса Stellar Burgers (Дипломный проект)

Проект реализован с использованием Selenium для UI-тестирования и REST Assured для подготовки и удаления данных через API.

## 🛠 Технологии и стек


| Технология | Версия |
| :--- | :--- |
| **Java** | 11 |
| **Selenium** | 3.141.59 |
| **JUnit** | 4.13.2 |
| **Rest Assured** | 4.4.0 (подготовка и очистка данных) |
| **Allure** | 2.15.0 (отчетность) |
| **WebDriverManager** | Управление драйверами браузеров |

## Что покрыто тестами

*   **Регистрация:**
    *   Успешное создание пользователя.
    *   Проверка ошибки при вводе пароля короче 6 символов.
*   **Авторизация (4 сценария):**
    *   Вход через кнопку «Войти в аккаунт» на главной.
    *   Вход через кнопку «Личный кабинет» в хедере.
    *   Вход через ссылку в форме регистрации.
    *   Вход через ссылку в форме восстановления пароля.
*   **Конструктор:**
    *   Проверка переключения вкладок: «Булки», «Соусы», «Начинки».
*   **Личный кабинет:**
    *   Переход в профиль, возврат в конструктор (по клику на лого и кнопку) и выход из аккаунта.

##  Особенности проекта
*   **API Pre-conditions:** Тестовые пользователи создаются через API перед тестами, что гарантирует независимость проверок.
*   **Авто-очистка (TearDown):** После каждого теста созданный пользователь удаляется через API по `accessToken`, чтобы не замусоривать базу данных.
*   **Page Object Model:** Код разбит на классы страниц с использованием `PageFactory` для удобной поддержки.
*   **Кроссбраузерность:** Реализована поддержка Chrome и Яндекс.Браузера через гибкую настройку драйвера.

## 🚀 Как запустить тесты

### 1. Запуск в Google Chrome
```bash
mvn clean test -Dbrowser=chrome
```

### 2. Запуск в Яндекс.Браузере
Для Яндекса используется системное свойство для указания пути к браузеру:
```bash
mvn clean test -Dbrowser=yandex -Dyandex.binary="C:\(\Program Files\Yandex\YandexBrowser\Application\browser.\)exe"
```

### 3. Генерация отчета Allure
Чтобы открыть отчет после завершения тестов, выполните:
```bash
mvn allure:serve
```
